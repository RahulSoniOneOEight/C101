# C101 Contract Package

These are review drafts produced under `CHG-017`. They do not change canonical ownership and do not
authorise production deployment.

## Contents

- `openapi/buildkart-experience-v1.yaml` — synchronous first-slice API.
- `asyncapi/buildkart-events-v1.yaml` — asynchronous event envelope and first-slice event families.
- `fixtures/` — representative consumer payloads for Flutter, web, seller and operator clients.

## Contract rules

- Commands are authenticated and authorised server-side.
- Consequential POST/PATCH operations require `Idempotency-Key` and/or `If-Match` as specified.
- `X-Correlation-Id` is accepted on requests and returned/generated by the platform.
- Money is integer minor units plus ISO currency.
- Read models expose version/freshness and backend-derived `allowed_actions`.
- Fixtures are contract examples, not production data or proof of runtime readiness.
- Revision 5 simulation is development/staging-only; simulated acceptance/refunds are test evidence,
  never provider capture or financial-refund evidence.
- Adapter mode is server-controlled. Production must fail closed if simulation is configured.
